Gameplay

• The paddle moves with the mouse
• The ball changes color with each bounce
• Earning enough points grants an extra life
• The game ends when the player runs out of lives
• Each row of bricks has a different point value

Victory

Clearing all the bricks totals in 420 points. Press OK to restart.

Failure

Losing all your lives ends the game. Press OK to restart.
